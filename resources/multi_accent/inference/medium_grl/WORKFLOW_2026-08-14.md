## 2. 三类推理条件

### Seen in-accent

- Speaker：从该口音 `test_seen` 中选择在训练集出现过的 speaker。
- Speaker embedding：从该 speaker 的随机 test reference WAV 提取 FACodec speaker embedding。
- Accent embedding：每条 utterance 独立从相同 target accent 的 test reference 中随机选择。
- Text：来自相同 target accent 的 seen/unseen test text。

### Unseen in-accent

- Speaker：从该口音 `test_unseen` 中选择训练集未出现的 speaker。
- Speaker embedding：从该 speaker 的随机 unseen test reference WAV 提取。
- Accent embedding：每条 utterance 独立从相同 target accent 随机选择。
- Text：来自相同 target accent 的 seen/unseen test text。

### Unseen cross-accent

- Speaker：使用 source accent 的 unseen speaker。
- Speaker embedding：从 source accent speaker 的随机 unseen test reference WAV 提取。
- Accent embedding：来自不同的 target accent。
- Text：来自 target accent。
- 每个 source accent 都覆盖其余 6 个 target accents。
- 每个 speaker–target-accent pair 合成 10 条。

## 5. Text 选择规则

最终重新选择了 1,350 条合成文本，并使用以下约束：

1. Text 必须来自相应 target accent 的 test set。
2. 每条文本至少包含 5 个汉字；标点、数字和英文不计入汉字数。
3. 1,350 条中文字符串全局不重复，而不仅是 WAV 路径不重复。
4. Text source WAV 也全部唯一。
5. 原始中文通过 `text_source` 回查语料的 `content.txt`、`UTTRANSINFO.txt`、`UTTERANCEINFO.txt` 或天津 TTS 的 `000001-000200.txt`，不从 phone sequence 反推汉字。

最终验证结果：

- 中文文本：1,350 条
- 唯一中文文本：1,350 条
- 最少汉字数：5
- 最大汉字数：57
- 缺失中文：0

## 6. Accent reference 选择规则

- 每条 inference case 独立随机选择一个 target-accent reference。
- Reference 必须来自对应 target accent 的 test set。
- Reference 原始 WAV 时长必须不少于 2.0 秒。
- 同一 reference 允许被不同 case 重复使用。
- Accent embedding 必须与所选 reference WAV 一一对应，使用 medium-GRL test embedding。

最终验证：

- 1,350 条 case 中小于 2 秒的 accent reference：0
- 最短 accent reference：2.000 秒
- 实际使用的唯一 accent reference：1,252 个
